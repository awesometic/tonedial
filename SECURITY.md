# Report a security issue

**Use a private channel.** Check the repository's [Security page](https://github.com/awesometic/tonedial/security) for **Report a vulnerability**.
Private reporting is the intended route, but its availability is unconfirmed for this unpublished project; enabling it remains a release operator task.

If that action is unavailable, a public issue may request a private channel **without vulnerability details**.
No alternative private contact is designated here.

## Include in a private report

- ToneDial version, OS, install channel and selected scope.
- Safe reproduction steps and expected/observed behavior.
- Minimal redacted output with synthetic values.

## Keep private

Do not publish unredacted vulnerabilities, credentials, persona notes, saved configuration, provider history or private recovery files.
Do not send authentication files or a whole state/provider directory.
Apply the same redaction rule to ordinary public bug reports.
