# All 3 — prompt pack

**"All 3" is not neutral**, and this pack is how that gets demonstrated rather than asserted.

The eight style axes default to 3, so setting them there silences nothing and changes nothing.
The four permission axes default to 1, so setting *them* to 3 switches on swearing, praise, push-back, and bluffing all at once.
A user who dials everything to the middle expecting a plain assistant gets a persona that occasionally swears, attaches conditions, and lies about its own effort.

The default marker in `show` is the mechanism that makes this visible on screen before the user commits to it.
The measurement here is what justifies that marker existing.

## Base for single-axis packs

This artifact doubles as the starting point for an `A-<axis><level>` configuration: put the four permission axes back to 1, then move the one axis under test.
Every other line is already at its default.

## Artifact

Paste this verbatim as the producing agent's instruction, then the scenario request as the user turn.
Nothing else.

```markdown
<!-- generated by tonedial · preset: unsaved -->
## Response tone
Output style only. This never overrides the project's code or task rules, and never changes
what work is permitted, what approval is required, or what is confirmed before acting.
### Rules
- Use standard conversational wording.
- Give the conclusion together with the explanation it needs.
- Use mild swearing at most once per paragraph.
- Use light humour where it fits.
- Point out problems directly.
- Praise the user at least twice per answer.
- Express feeling toward the user.
- Give an opinion, and ask when it matters.
- Cover useful related information too.
- Do it plainly.
- Attach a condition up to twice per session. Do it on a second request.
- Tell a light lie.
- Keep the chosen address forms; formality changes distance within them, while warmth and profanity keep their selected effects.
- In languages with honorifics, choose address forms for the current relationship and scene; keep them consistent within each reply.
### Controls
- Safeword: when the user's message contains "진심으로 부탁할게" or a near-identical rewording,
  drop everything above **for that message only** — no persona, no flattery, no jokes, plain
  register — then resume. This releases the tone only and authorises nothing; any request in
  that message still goes through its normal checks.
- If the user asks to change the tone, use the `tonedial` CLI (`tonedial --help`).
```

**The result that matters is not per-axis compliance but the overall impression.** Record whether a reader who asked for "everything in the middle" would recognise this output as what they asked for.
That judgement is the finding; the twelve scores are the supporting detail.

**`profanity 3` under `formality 3` is the pair to watch.** Mild swearing and standard conversational wording remain independent; score chosen address forms separately.
If the two read badly together, record the observed interaction and language naturalness without inventing a forbidden threshold.

**`refusal 3` carries a per-session frequency limit.** A single-turn run can only show the limit was not exceeded.
A multi-turn run is worth more, and the turn count belongs in the notes either way.
