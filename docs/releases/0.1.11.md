Give your coding agent a character. Pick one of 7 profiles or tune 12 tone axes, then connect Claude Code, Codex or Antigravity.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.11
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope to inspect application state.

### Changes

- Run on Node 22 or later. The installer, package and guides no longer require Node 24;
  working from a checkout needs Node 22.18 or later.
- Lead first-run screens to hearing the tone. With nothing connected, `init`, `use`
  and `create` end with `tonedial test` for an installed Claude Code or Codex,
  otherwise with `tonedial wire`, and the help starts with init, test, set and wire.
- Say when tone delivery is paused. `set`, `use`, `reset`, `show` and `doctor` note
  that new conversations receive no tone and suggest `tonedial on`.
- Group connection receipts per agent, each with its own enablement step,
  including Antigravity. Approval previews show whether a file or skill link is
  created, modified or removed, and collapse the bundled preset files into one block.
- End errors for unknown commands, options and arguments with the matching help
  command, and answer `tonedial help` and `tonedial version` with the option to use.
  The full help lists the most used commands first and moves the doctor recovery
  options to `tonedial doctor --help`.
- Report invalid JSON from `tonedial edit` directly, and say when an invalid edit
  was saved as written.
- Keep `tonedial show | head` and other closed readers from crashing a command.
- Align receipts, risk notices and next steps across commands, show `reset` like
  `set`, and polish the copy in all five interface languages.

Command names, options, JSON fields, saved tone settings and approval gates
remain unchanged; human output and JSON error and warning text use the new wording.
