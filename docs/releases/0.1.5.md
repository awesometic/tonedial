Set a coding agent's manner once and keep it across every project.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.5
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope to inspect application state.

### Changes

- Rework all twelve tone axes and their five levels with more observable targets
  for warmth, praise, profanity, criticism, brevity and other traits.
  Clarify `speech_level=rough` while keeping sentence endings separate from profanity and criticism.
- Improve rules for combinations such as brief replies with high warmth or praise,
  and preserve the configured persona when bravado increases.
- Ask for explicit approval in the current session before strong profanity, harsh mockery,
  fictional violent imagery or theatrical, noncredible menace, including requests from a persona.
  Increasing intensity or changing components requires new approval;
  profiles and `--auto` never supply it.
  Approval covers tone only and never permits protected-trait hate or realistic or credible threats.
- Preserve recovery of unmodified `TONE.md` artifacts generated by 0.1.4
  when refreshing the bundled tone instructions.
- Let `doctor --fix` quarantine unreadable operation records one at a time through the normal
  preview and approval gate, while retaining each record's exact original bytes and mode for rollback.
- Shorten dial hints across all five interface languages for smaller terminals,
  and improve multilingual example wrapping around inline code and punctuation.
- Add three copyable custom profile recipes for brief coding help, reassurance
  and rough-but-reliable help, and refine localized character address terms.
- Refresh the seven character examples and three custom recipes across five languages
  with 50 verbatim native Codex replies, and publish a separate 158-session calibration report
  using `gpt-6.1-sol` with high reasoning.

ToneDial remains in development.
Some axes may have a weaker effect than expected, and adjacent levels may sound similar.
Even with the same settings, results vary by model, language and conversation context.
The [calibration report](https://github.com/awesometic/tonedial/blob/v0.1.5/docs/results/2026-10-16-codex-high-tone-calibration.md)
records both observed differences and unresolved overlaps; it does not establish behavior for other models.
