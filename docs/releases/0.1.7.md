Set a coding agent's manner once and keep it across every project.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.7
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope to inspect application state.

### Changes

- Add `tonedial off` and `tonedial on` to pause and resume native tone delivery
  without deleting settings, profiles, connections or the full `TONE.md`.
- Expose the shared `enabled` state in settings and JSON receipts.
  While delivery is off, managed readers return an empty provider-valid response.
- Teach generated ToneDial controls to pause, resume and reload safely.
  Existing connections need a normal previewed `tonedial init` refresh
  before they can honor the off marker.
- Add a recorded `gpt-5.6-sol` / `high` comparison between Codex defaults
  and the complete `vibe-coder` profile, with exact replies, hashes and localized transcript images.
- Move first-run setup ahead of copyable recipes across all five READMEs,
  collapse long command and reply evidence, and clarify the linked Usage and Examples pages.

For a clean comparison with the model's ordinary manner, run `tonedial off`
and start a fresh conversation.
An open conversation may retain tone context delivered before it was paused.
The recorded comparison is one sample per condition; it does not isolate `verbosity=1`
or prove hook activation or repeated adherence.
