Set a coding agent's manner once and keep it across every project.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.4
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope to inspect application state.

### Changes

- Fix `doctor --fix` upgrades that failed after refreshing bundled presets,
  while still detecting replaced files and changed permissions.
- Keep edited retired preset definitions accessible after repair,
  and avoid duplicate recovered copies when repairs run again.
- Explain repair failures with the stage, affected path, safe error code and operation ID.
- Clarify interrupted-repair prompts with the full operation ID, Enter to cancel
  and separate approval for file changes.
- Focus `doctor` output on current blockers when an operation needs recovery,
  while retaining full history in `--verbose` and JSON,
  with clearer recovery guidance across all five interface languages.

If an earlier repair stopped, keep its operation records and follow the [recovery guide](https://github.com/awesometic/tonedial/blob/v0.1.4/docs/USAGE.md#recovery).
Run `tonedial doctor` in the same scope and use the exact command and operation ID it reports;
preview and approve the proposed changes.
