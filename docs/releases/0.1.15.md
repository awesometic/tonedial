Give your coding agent a character. Pick one of 7 presets or tune 12 tone axes, then connect Claude Code, Codex or Antigravity.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.15
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope.
It reports the bundled skill as out of date;
`tonedial doctor --fix` refreshes it in that scope.

### Changes

- Ask your agent to build a preset from a description, current research or a link.
  The ToneDial skill creates and applies it, then offers a quick check in a subagent or with `tonedial test`.
  Before reading a page link it warns you, and it stores nothing from the page until you approve the exact settings.
- `tonedial create` asks for an optional manner note after the agent and user roles.

Command names, options, JSON fields, saved settings and `TONE.md` output remain unchanged.

### Downloads

`tonedial-0.1.15.tgz` contains the exact archive published to npm.
