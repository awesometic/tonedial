Set a coding agent's manner once and keep it across every project.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.2
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor --fix` to refresh generated files.

### Changes

- Run approved npm updates directly, checking that npm manages the running ToneDial installation.
- Make update outcomes explicit and group file diagnostics with the applicable next action shown once.
- Remove repeated warnings for valid tone settings and successful profile writes across all five interface languages.
- Wait for npm metadata and the published archive before creating a GitHub Release, retrying every 15 seconds for up to 20 minutes while preserving integrity checks.

### Downloads

`tonedial-0.1.2.tgz` contains the exact archive published to npm.
`SHA256SUMS` provides its SHA-256 checksum.
GitHub also provides source archives for the release tag.
