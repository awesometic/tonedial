Give your coding agent a character. Pick one of 7 presets or tune 12 tone axes, then connect Claude Code, Codex or Antigravity.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.14
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope to inspect ToneDial's files.
It reports `TONE.md`, the bundled skill and the reader as out of date;
`tonedial doctor --fix` refreshes them in that scope.
This release includes the changes prepared for 0.1.12 and 0.1.13, which were not published.

### Changes

Tone and host style:

- Combine the tone with a host's own reply style instead of replacing either.
  Every `TONE.md` now asks the model to keep the format a host or user style requires,
  and to let `verbosity` set the explanation depth within it;
  a request in the current conversation overrides both.
- Keep a host's required response style when the Stop hook asks Claude Code or Codex
  to compress an overlong reply at `verbosity=1`.
- Map requests such as "show fewer tool calls" to the host's own display setting
  instead of the `verbosity` axis.

Connections:

- `show` lists connections per scope and folder, and `update` shows the installed and latest versions with their release dates.
- `wire` and `init --here` under a global connection write nothing and show how to move the connection to that folder,
  because a global hook already reaches every project.
- `unwire` and `eject` need a scope when the folder has its own connection,
  and `--here` refuses the home directory, including for `doctor --fix --tools`.
- `unwire --global` and `eject --global` also remove the project connections an earlier version recorded on a global hook.
- `doctor --fix --tools <agent>` adopts ToneDial entries that match exactly but have no record.
- A `--project` symlink resolves to its real folder, so a folder keeps one identity.
  A connection recorded under another spelling of its folder or home can now be removed and repaired.
- Bare `unwire` and `wire` pickers cancel on an empty answer.

Screens:

- Previews list each root once with relative rows and end a dry run with the command that applies it.
  `--verbose` keeps the full diff.
- `doctor` states health once, lists remaining steps at normal weight, groups a doubled hook by agent,
  names a settings file it cannot inspect, and shows rollback history only with `--verbose`.
- `list` shows each preset on two lines with a short risk mark, and `show <slug>` keeps the full explanation.
- `show` labels axis groups in the interface language, prints only the legends it uses,
  shows character counts only with `--verbose` and leaves out rows that a preset does not store.
- `use` says when it replaced unsaved edits, and a full `reset` ends with the way back to the saved preset.
- A refusal ends with the command to run, on its own line and in the right scope.
  Misspelled presets and keys suggest the nearest match, and `help <command>` points to that command's help.
- Risk notices use a yellow `!` on both output streams; a gauge's risky bar stays red.
- The interface says "preset" throughout, along with one scope label and "ToneDial files".

### Compatibility

Command names, options, saved tone settings and approval gates remain unchanged,
apart from the new refusals listed above.
`unwire --dry-run` and `eject --dry-run` also refuse while an operation needs recovery.

JSON output is additive:
refusals gain `reason` and `commands`, and new fields include `covered`, `alsoDisconnected`, `sharesGlobalHook`,
`installedVersion`, `latestVersion`, `installedPublishedAt`, `latestPublishedAt` and `createdParents`.
A `--project` symlink appears in JSON as its real folder.

Human output changed widely, so scripts should read `--json` rather than match labels such as
"Connection scope:", "Application:" or "already disconnected".
`update` now asks the npm registry for the latest version, waiting up to 10 seconds.

`TONE.md` gains one rule of about 400 characters.
Whether a model follows it depends on the host and model;
it has not been measured in native sessions yet.
