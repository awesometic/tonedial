Set a coding agent's manner once and keep it across every project.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.1
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor --fix` to refresh generated files.

### Changes

- Show the current `TONE.md` character count without arbitrary length targets or warnings.
- Set both roles interactively with `tonedial persona`, and read their full descriptions in `show`.
- Keep installer error checks consistent when the host uses a Korean locale.
- Publish a matching GitHub Release after the manual npm publishing workflow succeeds.

### Downloads

`tonedial-0.1.1.tgz` contains the exact archive published to npm.
`SHA256SUMS` provides its SHA-256 checksum.
GitHub also provides source archives for the release tag.
