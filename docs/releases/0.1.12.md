Give your coding agent a character. Pick one of 7 profiles or tune 12 tone axes, then connect Claude Code, Codex or Antigravity.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.12
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope to inspect application state.

### Changes

- Describe both forms of `unwire` in the help: naming a tool disconnects that agent,
  and running it with no tool disconnects every agent in the selected scope.
- Open the README with what ToneDial does and how it reaches each agent,
  and walk through the first run as `init`, `test`, `set` and `wire`.
  The Korean, Japanese, Chinese and Spanish READMEs follow the same flow.
- Align the usage guide with the current help and output, including paused
  delivery, per-agent connection receipts, recovery options and preview follow-ups.

Command names, options, JSON fields, saved tone settings and approval gates
remain unchanged.
