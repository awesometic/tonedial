Set a coding agent's manner once and keep it across every project.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.6
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope to inspect application state.

### Changes

- Fix `doctor --fix` becoming permanently blocked by an unreadable operation record
  even when no operation is running.
- Add `doctor --fix --quarantine-operation <id>` and show the exact scoped command
  when recovery finds an unreadable record.
- Preserve the selected record's exact original bytes and mode in a separate rollback operation,
  while replacing it with a nonblocking marker only after preview and approval.
- Handle several unreadable records one at a time, with an independent rollback and next command
  for each record; continue the application rebuild after the last record is quarantined.
- Distinguish active operations from unreadable history and clarify the recovery flow
  across all five interface languages and generated agent controls.

If ToneDial 0.1.5 reports unreadable operation history, do not delete files under the state root.
Upgrade, run `tonedial doctor` in the same scope, and follow each reported
`--quarantine-operation` command until application recovery completes.
