Set a coding agent's manner once and keep it across every project.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.3
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor --fix` to refresh generated files.
For npm permission errors, follow the [backup and reinstall steps](https://github.com/awesometic/tonedial/blob/v0.1.3/docs/USAGE.md#npm-permissions).

### Changes

- Add `tonedial get [key]` to read one or all current editable settings.
  A key adds its meaning and choices; JSON preserves numbers, full text and unset values.
- Add `speech_level=rough` for rough, cheeky non-honorific sentence endings.
  Keep ordinary `plain` forms, configured address terms and independent tone axes unchanged.
  Preserve the new value through profile transfers and application recovery.
- Detect npm update permission errors and guide users through backup and reinstall in a user-owned directory.
  Never retry with elevated privileges automatically.
- Show complete persona notes and clearer register labels, and shorten repeated safeword summaries across all five interface languages.

Profiles using `rough` require a CLI that supports that value; older versions reject them.
