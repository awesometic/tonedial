Set a coding agent's manner once and keep it across every project.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.9
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope to inspect application state.

### Changes

- Keep standalone paths and commands copyable while wrapping hook guidance
  within the terminal width.
- Show the available `speech_level` values in setting queries and help.
- Keep the interactive dial usable at 60×24 and 80×24 when localized hints
  need more room, while refusing edits when the complete preview cannot fit.
- Group unconnected agent checks after connected checks and separate recovery
  receipts from the follow-up diagnosis.
- Name the affected agents in disconnect receipts and report an already
  disconnected state when only config formatting changes.
- Shorten preview and hook guidance across the five interface languages,
  and clarify editing, recovery and connection instructions in the guides.

Command names, options, JSON fields, saved tone settings and approval gates
remain unchanged.
