Give your coding agent a character. Pick one of 7 profiles or tune 12 tone axes, then connect Claude Code, Codex or Antigravity.

### Install or upgrade to this release

```bash
npm install --global tonedial@0.1.13
```

Use `tonedial update` for npm or curl installations; it asks before updating.
After updating, run `tonedial doctor` in the same scope to inspect application state.
It reports `TONE.md`, the bundled skill and the reader as out of date;
`tonedial doctor --fix` refreshes them in that scope.

### Changes

- Combine the tone with a host's own reply style instead of replacing either.
  Every `TONE.md` now asks the model to keep the format a host or user style requires,
  such as a Claude Code output style leading with the answer,
  and to let `verbosity` set the explanation depth within it;
  a request in the current conversation overrides both.
  Codex `model_verbosity` is an API setting the model does not see as text,
  so for Codex the tone only keeps its depth request alongside it.
- Keep a host's required response style when the Stop hook asks Claude Code or Codex
  to compress an overlong reply at `verbosity=1`.
- Map requests such as "show fewer tool calls" or "hide the thinking" to the host's
  own display setting, such as the Antigravity CLI's `/config` Verbosity, instead of the
  `verbosity` axis, while a request to drop the reply's own work narrative still changes the tone.
- Explain in the usage guide how ToneDial's `verbosity` relates to host display and reply-style settings.

Command names, options, JSON fields, saved tone settings and approval gates
remain unchanged; `TONE.md` gains one rule of about 400 characters.
Whether a model follows the new rule depends on the host and model;
it has not been measured in native sessions yet.
