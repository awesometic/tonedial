tonedial — set a coding agent's manner once and keep using it

tonedial <command> [options]

To get started, set up, preview and adjust your tone, then connect an agent:
  tonedial init --tools none --global
  tonedial test
  tonedial set
  tonedial wire

Tone
  set <key>=<value>...  change axes, role or settings · no args opens the dial
  show [slug]           show settings · a slug previews a saved profile
  get [key]             show current values · a key adds meaning and choices
  reset [axis]          reset one axis · no args resets all twelve
  address [self user]   set the agent's and your names · no args prompts ·
                        frequency: set address_frequency=rarely
  persona [agent user]  set the agent's role and yours · no args prompts
  test [claude|codex]   preview your tone or a preset in a new conversation
  off                   pause tone delivery · keep settings and TONE.md
  on                    resume saved tone delivery

Preset library
  list                  list bundled and saved presets
  use <slug>            apply a preset
  create [name] ...     create and apply a preset · no args guides setup
  save [display name]   save the current tone as a profile
  export <slug>         back up a profile, including address and role, as JSON
  import <file>         import a profile from JSON · use applies it
  edit [preset <slug>]  open settings or a preset in $EDITOR

Connections
  init                  set up and refresh bundled files
  wire [tool]           connect an agent in the chosen scope · no args prompts
  unwire [tool]         disconnect one agent in the selected scope
  doctor                check connections · repair with --fix
  eject                 disconnect agents in the selected scope · keep presets

Maintenance
  compile               rebuild TONE.md · tone changes already do this
  update                update this install

Options
  --global              global scope (default) · state it for --auto writes
  --here                current project scope
  --project=DIR         another project directory · use: export TONE.md there
  --migrate-legacy      init: approve validated older state
  --auto                skip approval prompt · always show diff
  --dry-run             show changes · write nothing
  --lang=CODE           init: interface language (en, ko, ja, zh, es)
  --commands            init: also install /tone
  --tools=LIST          agents to connect · init: none = state only
  --fix                 doctor: repair fixable findings
  --preset=SLUG         test: preview a saved profile · current state kept
  --slug=SLUG           create/save: preset slug (lowercase, digits, dashes)
  --accept-usage        test: accept account usage and charges for this launch
  --explain             show: explain axes, settings, risky levels
  --check               compile: report size · write nothing
  --json                machine-readable output with schema
  -v, --verbose         command details, diagnostics, and diffs
  --color=MODE          auto (default), always, or never
  --version             version · --verbose adds Node and schema
  --help                this text
  Recovery options for doctor --fix: tonedial doctor --help

Connection commands use the global scope unless you pass --here (current
project) or --project DIR. Unattended writes need the scope stated explicitly.
Command help: tonedial <command> --help
