tonedial — 코딩 에이전트의 말투를 한 번 정하고 계속 씁니다

tonedial <command> [options]

시작하기: 초기 설정 후 말투를 조정하고 에이전트를 연결하세요:
  tonedial init --tools none --global
  tonedial set
  tonedial wire

말투
  set <key>=<value>...  축·역할·설정 변경 · 인자 없으면 다이얼
  show [slug]           현재 설정 · 슬러그를 주면 저장한 프로필
  get [key]             현재 설정값 조회 · 키를 주면 의미와 선택지도 표시
  reset [axis]          축을 기본값으로 · 축을 안 주면 전부
  address [self user]   서로 부르는 말 · 인자 없으면 질문 · 빈도: set
                        address_frequency=rarely
  persona [agent user]  에이전트·사용자 역할 · 인자 없으면 질문
  test [claude|codex]   저장된 설정이나 프리셋으로 새 대화 시작
  off                   말투 전달 일시정지 · 설정·TONE.md 유지
  on                    저장한 말투 전달 재개

프리셋 보관함
  list                  기본 제공·사용자 프리셋
  use <slug>            프리셋 적용 후 컴파일
  create [name] ...     프리셋 생성·적용 · 인자 없으면 안내
  save [display name]   현재 말투를 프로필로 저장
  export <slug>         호칭·역할을 포함한 프로필을 JSON으로 백업
  import <file>         JSON에서 프로필 가져오기 · use로 적용
  edit [preset <slug>]  설정이나 프리셋을 $EDITOR로 열기

연결
  init                  초기 설정과 기본 파일 갱신
  wire [tool]           선택한 범위에 에이전트 연결 · 인자 없으면 질문
  unwire [tool]         관리 중인 연결 해제
  doctor                연결 점검 · 복구는 --fix
  eject                 선택한 범위의 모든 에이전트 연결 해제 · 프리셋 유지

관리
  compile               TONE.md 재생성 · 말투를 바꾸면 자동 처리
  update                현재 설치 업데이트

옵션
  --global              전역 범위(기본값) · 지정하면 범위를 명시한 것으로 처리
  --here                현재 프로젝트 범위
  --project=DIR         다른 프로젝트 디렉터리 · use: 그곳에 TONE.md 내보내기
  --migrate-legacy      init: 검증된 이전 상태를 옮기도록 승인
  --auto                승인 질문 생략 · diff는 계속 표시
  --dry-run             변경 내용만 표시 · 기록하지 않음
  --lang=CODE           init: 인터페이스 언어(en, ko, ja, zh, es)
  --commands            init: /tone 명령도 설치
  --tools=LIST          연결할 에이전트 · init에서 none은 상태만 준비
  --fix                 doctor: 고칠 수 있는 문제 복구
  --preset=SLUG         test: 저장한 프로필 미리보기 · 현재 상태 유지
  --slug=SLUG           create/save: 프리셋 슬러그(영문 소문자, 숫자, 대시)
  --accept-usage        test: 이번 실행의 계정 사용량·비용 부담에 동의
  --explain             show: 축·설정·주의할 레벨 설명
  --check               compile: 크기만 확인 · 기록하지 않음
  --json                스키마를 포함한 기계용 출력
  -v, --verbose         자세한 설명·진단·diff
  --color=MODE          auto(기본), always, never
  --version             버전 · --verbose로 Node와 스키마 확인
  --help                이 화면
  doctor --fix 복구 옵션: tonedial doctor --help

연결 명령은 기본적으로 전역 범위를 씁니다. 현재 프로젝트는 --here, 다른
디렉터리는 --project DIR로 선택하세요. 질문 없이 파일을 바꾸려면 범위를 직접
지정해 주세요.
명령별 도움말: tonedial <command> --help

문제가 발생했거나 아이디어, 피드백이 있으시면 자유롭게 작성해 주세요 :)
