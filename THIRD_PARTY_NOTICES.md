## Unicode Character Database

`src/ui/width.ts` is generated by `scripts/generate-width-table.py` from Python 3.14's `unicodedata`, which exposes the East Asian Width property of the Unicode Character Database (Unicode 16.0.0).
The generated ranges are what keep a gauge column aligned in Korean, Japanese and Chinese, and they are compiled into `dist/ui/width.js`, so they travel inside the npm package.
